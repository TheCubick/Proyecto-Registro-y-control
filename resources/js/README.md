# Frontend structure

- `app.jsx`: React and Inertia entry point.
- `bootstrap.js`: frontend bootstrap code.
- `Components/`: reusable visual components.
- `Components/ui/`: generic UI components such as buttons, alerts, modals and tables.
- `Components/forms/`: reusable form fields and form sections.
- `Layouts/`: reusable page shells and navigation layouts.
- `Pages/`: route-level pages that are not shared between modules.
- `Pages/Departments/`: department pages.
- `Pages/Visitors/`: visitor pages.
- `Pages/Visits/`: visit pages.
- `hooks/`: reusable React hooks.
- `lib/`: shared helpers and frontend configuration.
